# 📊 PhonePe Pulse Dashboard

## Project Overview

The PhonePe Pulse Dashboard is a data visualization project developed using Python, Streamlit, MySQL, Pandas, and Plotly. It analyzes PhonePe Pulse transaction data and presents interactive charts and insights through a user-friendly dashboard.

---

## Features

- Interactive Dashboard
- State-wise Transaction Analysis
- Year-wise Data Filtering
- Total Transaction Amount
- Total Transaction Count
- Top 10 States Analysis
- Bar Chart Visualization
- Pie Chart Visualization
- India Transaction Map
- MySQL Database Integration

---

- Python
- Streamlit

- Pandas

## Installation

### Clone Repository

```bash
git clone https://github.com/jinaldodiya/PhonePe-Pulse-Dashboard.git
```

### Install Required Libraries

```bash
pip install streamlit pandas mysql-connector-python plotly
```

### Run Project

```bash
streamlit run app.py
```

---

## Database

Create a MySQL database named:

```
phonepe
```

Import the required tables before running the application.
